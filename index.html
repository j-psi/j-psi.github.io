Repository Directory & Jekyll Setup

To serve PDFs and MP4s directly from your GitHub repository under jdavis, create the following directory structure and configuration files in your main branch:

Repository File Hierarchy:

jdavis.github.io/
├── _config.yml
├── index.html (or index.md)
└── assets/
    ├── pdfs/
    │   ├── system-architecture.pdf
    │   └── research-paper.pdf
    └── videos/
        ├── demo-walkthrough.mp4
        └── project-presentation.mp4
_config.yml 
title: jdavis | GitHub Pages
description: Personal site featuring technical blog posts, PDFs, and MP4 video recordings.
theme: jekyll-theme-merlot

# Repository Base Settings
url: "https://jdavis.github.io"
baseurl: ""

# Ensure assets are processed and served correctly
include:
  - assets/pdfs/
  - assets/videos/

plugins:
  - jekyll-seo-tag
